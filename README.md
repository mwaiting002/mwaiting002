### 6D 姿态估计

**6D pose estimation** · 2025.12.23

[项目笔记](https://mwaiting002.github.io/projects/pose-6d.html) · [深度学习版](https://www.bilibili.com/video/BV1unBNBZEmL) · [传统 CV 版](https://www.bilibili.com/video/BV1XoBNBAEbE) · [6D 定位 + MoveIt 2](https://www.bilibili.com/video/BV1UziyBcE7b)

**问题 · Problem**  
同一天的两条视频都在做物体的 6D 姿态估计：一个深度学习版，一个传统计算机视觉版。帖子没有写评测集，也没有写目标精度。  
*Two videos posted the same day estimate an object's 6D pose: a deep-learning version and a classical computer-vision version. The posts name no benchmark and no target accuracy.*

**方法 · Method**  
深度学习版：相机是 RealSense D415，使用 FoundationPose 的 ROS 2 版本。CAD 用腾讯混元建模，再用建模工具微调。  
传统版：相机是奥比中光 Gemini 335。方法是特征点匹配，加上深度法向量。  
2026-01-07 还有一条相关视频，「6D姿态视觉定位+Moveit2规划」。简介只写了系统为 Ubuntu 22.04、ROS 2 Humble。  
*Deep learning: a RealSense D415 and the ROS 2 build of FoundationPose. CAD from Tencent Hunyuan, then a modeling-tool tweak. Classical: an Orbbec Gemini 335; feature matching plus depth normals. A related video on 2026-01-07, “6D姿态视觉定位+Moveit2规划”, only says the system is Ubuntu 22.04 and ROS 2 Humble.*

**结果 · Result**  
两条简介都没有给出误差或成功率。公开出来的结果就是那两条录像。  
*Neither description gives an error or a success rate. The recordings are the result that was published.*
